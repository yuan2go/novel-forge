# Prose Generation

## 适用场景

- 根据章节细纲生成正文 v0 或修订稿。
- 将场景目标、冲突、行动和情绪变化转化为可审稿文本。
- DeepSeek 或其他正文模型需要明确写作边界时。

## 输入要求

- 已通过 `chapter-outline` 检查的章节细纲。
- 项目宪法、当前上下文、人物状态、世界规则、风格规则。
- 禁止复用内容、原创风险边界和本章审稿重点。

## 操作流程

1. 读取细纲，不新增未经授权的主线设定。
2. 按场景顺序写作，先行动和冲突，后解释设定。
3. 控制叙述密度：每个场景必须有信息增量或情绪变化。
4. 通过对白、动作、选择和代价体现人物，不用旁白替人物解释。
5. 确保爽点通过行动兑现，结尾留下追读钩子。
6. 生成后自检章节功能是否完成。
7. 输出正文草稿和自检报告，不直接标记为 final。

## 输出格式

```markdown
# 第 N 章正文 v0

## 正文

## 自检

- 是否完成本章目标：
- 是否有明确冲突：
- 是否有信息增量：
- 是否有读者爽点：
- 是否有代价：
- 是否有结尾钩子：
- 是否违背项目宪法：
- 是否存在原创风险：
- 是否存在 AI 腔：
```

## 质量标准

- 正文必须严格服务细纲，不能脱纲扩展新主线。
- 开头必须尽快进入异常、冲突或压力。
- 每章结尾必须给出下一章阅读理由。
- 解释不能压过行动，多学科知识只能服务可信度。
- 生成稿必须进入 `quality-review`，不能直接进入 final。

## 禁止事项

- 禁止无细纲生成正文。
- 禁止覆盖 `*_final.md`。
- 禁止复制热门小说表达、桥段、人物或独特设定。
- 禁止用总结式 AI 腔替代场景推进。

## 与其他模块的关系

- 上游：`chapter-outline`、项目宪法、风格规则、当前上下文。
- 下游：`quality-review`、修订任务、memory 更新。
- Agent：正文 Agent、DeepSeek、Claude Code 调度使用。
