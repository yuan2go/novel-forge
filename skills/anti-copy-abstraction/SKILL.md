# Anti Copy Abstraction

## 适用场景

- 热门小说拆解后，需要进入题材、人物、大纲或正文前。
- 拆解报告中存在具体桥段、人物关系、独特反转或世界设定风险。
- 审稿时怀疑某个产物过度接近已有作品。

## 输入要求

- 输入必须包含来源标识、拆解报告、可复用点和禁止复用点。
- 不接受无来源的“爆款套路”直接进入生成链路。
- 如果输入包含具体剧情，必须先标记为高风险内容。

## 操作流程

1. 将输入拆分为表达、剧情、设定、结构、机制、读者效果六类。
2. 删除或标记表达、具体剧情、独特设定和可识别人物组合。
3. 保留结构、机制和读者效果。
4. 将具体桥段改写为类型无关的因果机制。
5. 为每条原则补充适用范围、禁用范围和审稿检查项。
6. 输出可进入知识库或创作流程的抽象原则。

## 输出格式

```markdown
# 反抄袭抽象报告

## 输入来源

## 高风险具体内容

## 删除或禁用内容

## 抽象机制

## 可复用创作原则

## 适用题材

## 审稿检查项

## 原创风险等级

## 是否允许进入下游
```

## 质量标准

- 输出不能让创作者复原原作品的具体桥段。
- 每条抽象原则必须脱离单一作品语境也能成立。
- 必须明确哪些内容不能进入 prompt、模板、正文和素材库。
- 必须能被 `quality-review` 用作原创风险检查依据。

## 禁止事项

- 禁止保留可识别人物组合。
- 禁止保留独特反转和具体案件结构。
- 禁止用“致敬”“参考风格”规避版权边界。
- 禁止将拆解结果直接交给 `prose-generation`。

## 与其他模块的关系

- 上游：`hot-novel-deconstruction`、审稿报告、风险控制文档。
- 下游：题材、世界观、人物、大纲、审稿。
- Agent：拆书 Agent、审稿 Agent、题材策划 Agent 必须使用。
