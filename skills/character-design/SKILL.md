# Character Design

## 适用场景

- 创建主角、反派、配角或关键关系人物。
- 审查人物是否能推动主线冲突。
- 大纲或细纲中出现人物动机漂移、降智或工具人问题。

## 输入要求

- 项目宪法或项目方向。
- 题材、目标读者、核心冲突、世界观规则。
- 已有人物关系、主线目标和阶段剧情需求。

## 操作流程

1. 明确人物在主线中的功能：推动者、阻碍者、诱因、镜像、代价承担者。
2. 定义人物目标、欲望、恐惧、执念和底层缺口。
3. 定义能力、资源、限制、缺陷和行动代价。
4. 建立关系网：利益关系、情感关系、秘密关系和冲突关系。
5. 设计成长弧：开局信念、中段崩塌、关键选择、最终变化。
6. 检查每个关键行动是否服务主线冲突或人物成长。
7. 输出人物卡和崩人设风险清单。

## 输出格式

```markdown
# 人物卡

## 基础身份

## 主线功能

## 外部目标

## 内在欲望

## 恐惧与执念

## 能力与资源

## 缺陷与代价

## 关系网

## 成长弧

## 行为逻辑

## 不可做的事

## 主线冲突贡献
```

## 质量标准

- 人物行动必须有欲望、压力、选择和代价。
- 关键人物必须能制造或解决主线冲突。
- 反派必须有可理解的收益和压力，不只是阻碍工具。
- 配角不能只负责解释设定或推动主角升级。

## 禁止事项

- 禁止让人物为了剧情需要突然降智。
- 禁止只写标签化人设，不写行为逻辑。
- 禁止让人物成长弧脱离主线冲突。
- 禁止复用具体作品的人物身份组合和关系组合。
