# 06. Project Differentiation Gate 项目差异化 Gate

## 1. 模块目标

Project Differentiation Gate 用于防止多本小说因为共用全局知识、世界模板和生产流程而同质化。

它回答的问题是：

```text
这本新小说和已有项目有什么不同？
是否值得作为一个独立项目存在？
是否只是已有项目的换皮版本？
```

## 2. 为什么需要差异化 Gate

NovelForge 支持多本小说并行生产，且多本小说会共用：

```text
网文商业结构库
多学科可信度知识库
哲学命题库
世界模板库
审稿规则库
```

如果缺少差异化检查，系统容易生成：

1. 相似主角；
2. 相似开局；
3. 相似反派；
4. 相似哲学命题；
5. 相似爽点；
6. 相似世界规则；
7. 相似章节节奏。

## 3. 输入

```text
新项目候选方案
project_registry.md
project_matrix.md
已有世界实例
已有哲学命题
已有主角类型
已有商业爽点结构
已有目标读者画像
```

## 4. 输出

```text
project_differentiation_gate.md
similarity_score
differentiation_score
必须调整项
是否允许立项
```

## 5. 检查维度

```text
1. 类型是否重复；
2. 主角身份是否重复；
3. 主角欲望是否重复；
4. 初始压迫是否重复；
5. 哲学命题是否重复；
6. 世界模板是否重复；
7. 核心爽点是否重复；
8. 反派结构是否重复；
9. 开局钩子是否重复；
10. 语言风格是否重复；
11. 目标读者是否完全重叠；
12. 前十章节奏是否相似。
```

## 6. 差异化矩阵

路径：

```text
03_project_registry/project_matrix.md
```

示例：

| 项目 | 类型 | 世界 | 哲学命题 | 主角欲望 | 核心爽点 | 风格 |
|---|---|---|---|---|---|---|
| A 黑档案 | 都市悬疑 | 档案身份世界 | 自由 vs 秩序 | 找回身份 | 揭秘反杀 | 冷峻压迫 |
| B 灵市 | 玄幻经营 | 灵石垄断世界 | 力量 vs 代价 | 掌控资源 | 经营升级 | 爽快热血 |
| C 记忆税 | 赛博科幻 | 记忆税世界 | 真实 vs 幸福 | 夺回记忆 | 信息战 | 诡异黑暗 |

## 7. 相似度判断

### 7.1 低风险

相似度低于 40%。

可以立项。

### 7.2 中风险

相似度 40%-60%。

需要调整至少两项：

```text
主角身份
核心爽点
哲学命题
反派结构
世界区域
叙事风格
```

### 7.3 高风险

相似度超过 60%。

必须调整至少三项，否则暂停立项。

## 8. 差异化策略

如果新项目与已有项目过于相似，可以从以下维度重构：

```text
1. 换主角阶层：底层 / 中层 / 上层 / 边缘者；
2. 换主角欲望：复仇 / 求生 / 夺权 / 揭秘 / 保护 / 逃离；
3. 换哲学命题：自由 vs 秩序 / 真相 vs 幸福 / 力量 vs 代价；
4. 换世界区域：城市 / 边疆 / 宗门 / 黑市 / 战场；
5. 换叙事风格：热血 / 冷峻 / 诡异 / 轻松 / 黑暗；
6. 换反派逻辑：秩序维护者 / 资源垄断者 / 旧制度受益者 / 伪善拯救者；
7. 换爽点来源：打脸 / 揭秘 / 信息战 / 经营 / 战斗 / 权谋。
```

## 10. 通过标准

一个项目要通过差异化 Gate，必须满足：

1. 与已有项目核心卖点不重复；
2. 主角欲望不重复；
3. 哲学命题不完全重复；
4. 爽点来源有明确差异；
5. 反派结构有明确差异；
6. 开局异常有明确差异；
7. 语言风格或叙事气质有差异；
8. 不只是换名、换世界皮肤。
