# Current Roadmap

Updated: 2026-08-11

The current priority is engineering convergence, not new Novel OS features.

## Completed foundation

- one Book production composition shared by API and Worker;
- PostgreSQL-only production state authority;
- two-chapter no-Replan and explicit-Replan-approval fixture proofs;
- canonical pytest collection with non-zero required-module checks;
- unified runtime environment/control-level type;
- shared Provider adapter composition over the Production Execution Gateway;
- RuntimeJob limited to operational scheduling envelopes;
- code-derived production reachability manifest;
- capability/stage-optional Knowledge Pack contract;
- first removal/isolation of duplicate runtime aliases and topology.

## Remaining P1

1. Obtain green GitHub Actions execution on the final SHA. Code cannot resolve an
   account billing/spending-limit block; rerun after account state is repaired.
2. Run credentialed Provider qualification through the canonical composition and
   persist current-SHA evidence without raising the proof ceiling prematurely.
3. Complete call-graph retirement of legacy LocalStorage/Celery/product workflow
   consumers, then delete isolated workflow/loop, production-kernel, agent-
   scheduler, and legacy context services in vertical slices.
4. Turn static reachability into deployment-attested reachability without making
   deployment state an editable source manifest.
5. Finish production operations evidence: secrets, authentication, backup/PITR,
   capacity, SLO, and incident recovery.

## P2 after P1 gates

- real-provider two-chapter proof with cost/usage/query/cancel/recovery evidence;
- sustained long-form and multi-book proof;
- quality calibration against governed evaluation sets;
- policy-governed low-risk auto approval, only as a separate design after the
  explicit approval path remains authoritative;
- user-facing production operations and publishing proof.

Do not resume horizontal feature expansion while Provider, remote CI, deployment,
and legacy-retirement evidence remains incomplete. A module, schema, test fixture,
or document is not production proof.
