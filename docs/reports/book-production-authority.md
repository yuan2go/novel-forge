# Book Production Authority

`book.production.run` is a PostgreSQL Root Saga with frozen Book policy. The fixture
graph proves Book preparation, sequential chapter-dispatch children, light/formal
recap cadence, proposal-only future plan adjustment, dependencies, pause/resume and
root completion. Chapter acceptance records explicitly say scripted fixture and do
not contain generated prose. Future plans are proposals; frozen child Operations are
not mutated.

This is an executable orchestration skeleton, not a real 3-chapter or long-form
quality proof. Cancellation/budget fields are frozen in policy; provider cost and
real Chapter Saga delegation remain next-stage integration work. Evidence:
`modules/book_authority/`, PostgreSQL fixture test, commit `4863a67`.
