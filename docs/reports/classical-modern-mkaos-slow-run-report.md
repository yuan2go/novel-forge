## Full Provider Decomposition Policy

Literal one-shot provider decomposition of all 22,612 chapters is not used because it removes batch recovery, cost control, and failure isolation. The accepted full-run mode is one operator command that loops governed batches until the ledger reaches full coverage. Each inner batch keeps `--provider-max-calls <= 50`, writes checkpoint/ledger/report, skips already processed content hashes, and produces reviewable candidates only.

Recommended iTerm2 command:

```bash
while true; do
  CODEX_HOME=/Users/yuan/.codex-claude python3 scripts/import_classical_modern_to_mkaos.py \
    --repo-path .local/external/Classical-Modern \
    --storage-root .local/workspace \
    --project-id classical-modern-mkaos \
    --confirm-full-run \
    --index-only \
    --run-provider \
    --provider-batch-size 1 \
    --provider-max-calls 50 \
    --provider-source-chars 3600 \
    --sleep-seconds 2 \
    --resume \
    --skip-existing \
    --checkpoint-path .local/workspace/classical-modern-mkaos/checkpoints/import-checkpoint.json \
    --ledger-path .local/workspace/classical-modern-mkaos/ledgers/provider-extraction-ledger.jsonl \

    --report-path docs/reports/classical-modern-mkaos-slow-run-report.md
  python3 - <<'PY' || break
import json
from pathlib import Path
ledger = Path(".local/workspace/classical-modern-mkaos/ledgers/provider-extraction-ledger.jsonl")
processed = set()
failed = 0
for line in ledger.read_text(encoding="utf-8").splitlines() if ledger.exists() else []:
    try:
        row = json.loads(line)
    except Exception:
        continue
    if row.get("status") == "succeeded" and row.get("content_hash"):
        processed.add(str(row["content_hash"]))
    elif row.get("status") == "failed":

print(f"provider processed unique content hashes: {len(processed)} / 22612; failed rows: {failed}")
raise SystemExit(0 if len(processed) < 22612 else 1)
```
