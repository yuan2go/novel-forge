# Deprecated Designs

## Deprecated For V5 Phase 1

- Mixed V1/V4 directory compatibility inside the same project.
- Document-only module completion.
- Unclear distinction between source, decomposition, and generated assets.
- Model-specific calls in workflow logic.
- External infrastructure before local pipeline stability.

## Deferred

- Qdrant, Neo4j, Redis, Celery, Web UI.
- Real external LLM calls.
- Pydantic/pytest dependencies until dependency policy is approved.
