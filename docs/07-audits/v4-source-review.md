# V4 Source Review

## Read Scope

The V4 source review covered the old project root files, 32 Markdown documents under `docs/`, core scripts, tests, schemas, progress logs, and audit reports.

## Findings

- V4 captured a broad business vision: reference decomposition, knowledge/material libraries, topic/world/character/outline/chapter/draft/review/feedback loops.
- V4 implementation was still file-project oriented and skeletal.
- Existing useful assets included AI collaboration rules, V4 audit reports, progress/task logs, initial JSON schemas, and document-structure tests.
- The docs were ahead of implementation for most creative modules.

## Conflict Handling

Where V4 docs and code diverged, V5 adopts the long-term business target from docs and implements a smaller executable core rather than preserving the old layout.
