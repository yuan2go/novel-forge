# Source, intelligence, and knowledge

The source pipeline turns governed external material into traceable, abstract knowledge without letting raw source expression become novel prose.

```text
Source repository/object
      ↓ acquisition policy, immutable commit/blob identity
Source Import manifest
      ↓ normalization and structural chunking
Source Authority documents/chunks
      ↓ rights gate and analysis routing
Source Intelligence observations
      ↓ evidence spans + abstraction validation
MKAOS knowledge candidates
      ↓ Authority approval
KnowledgeCard versions
      ↓ frozen selection
KnowledgePack
      ↓
Context selection (subject to source isolation)
```

## Source Import

Source Import accepts governed HTTPS GitHub identities and, only in fixture environments with an explicit root, local file repositories. It freezes a repository commit, applies path/type/size policies, normalizes supported text formats, creates bounded structural chunks, and records a resumable manifest. Symlinks, submodules, Git LFS, credentials in URLs, and unsupported formats fail closed.

## Source Authority and Intelligence

Source Authority owns rights, lifecycle, eligibility, governance, document identity, and transformation evidence. Unknown or forbidden rights are quarantined. Intelligence routing selects a bounded analysis profile from actual document evidence; observations remain linked to source chunks and are not draft prose.

## MKAOS

MKAOS validates abstract knowledge candidates, copyright boundaries, evidence spans, and pack selection. Candidate payloads reject raw-text, quote, excerpt, and similar source-expression fields. Approval creates governed KnowledgeCard versions; pack construction freezes version identities, roles, and weights.

MKAOS is a knowledge authority, not Canon and not StoryState. Knowledge may constrain or inform generation, but only a domain acceptance path can make a fact or plan active.

## Current proof boundary

The import, governance, deconstruction, candidate, approval, and pack operations are present in the production entry manifest and have fixture/integration test suites. The repository does not prove arbitrary source types, unrestricted repository ingestion, or that source-derived knowledge has produced a sustained real-provider novel.
