# 03. 世界实验室 World Lab

## 1. 模块目标

世界实验室负责管理世界模板、共享世界实例、世界分支和世界规则合并机制。

它的作用不是直接写小说，而是为项目孵化提供可复用的世界运行机制。

## 2. 为什么需要世界实验室

多本小说如果完全从零构建世界，会导致：

1. 设定经验无法沉淀；
2. 世界运行规则重复设计；
3. 每本小说都要重新解决资源、权力、社会、法律问题；
4. 长期无法形成小说宇宙资产。

但如果所有小说直接共享同一个世界，又会导致：

1. 世界互相污染；
2. 时间线冲突；
3. 单本小说不独立；
4. 读者理解成本增加；
5. 多项目维护复杂。

所以世界实验室采用三层设计。

## 3. 世界三层结构

```text
World Template
  ↓
World Instance
  ↓
Novel Project Branch
```

### 3.1 World Template

世界模板是通用模型，不属于某一本小说。

例如：

```text
资源垄断型玄幻世界
档案身份型悬疑世界
记忆税型赛博世界
帝国官僚型权谋世界
末日资源稀缺型世界
神权合法性型世界
```

### 3.2 World Instance

世界实例是从世界模板生成出的具体世界。

例如：

```text
world_black_archive_v1
world_spirit_market_v1
world_memory_tax_v1
```

### 3.3 Novel Project Branch

单本小说在某个世界实例下的局部分支。

单本小说只能修改自己的 branch，不能直接修改共享世界主线。

## 5. 世界模板标准结构

```markdown
# 世界模板：资源垄断型玄幻世界

## 1. 世界核心机制

世界中最关键的资源被少数组织控制，所有修炼、身份、阶层、战争都围绕该资源展开。

## 2. 世界第一规则

任何力量增长都必须消耗资源、时间、风险或社会关系。

## 3. 可生成的冲突

1. 底层无法获得资源；
2. 宗门垄断灵矿；
3. 黑市走私；
4. 主角发现替代资源；
5. 既得利益集团打压主角；
6. 资源体系改变引发秩序重组。

## 4. 适合哲学命题

- 力量 vs 代价；
- 自由 vs 秩序；
- 个人突破 vs 资源垄断；
- 公平 vs 效率。

## 5. 必须回答的问题

1. 资源从哪里来？
2. 谁控制资源？
3. 普通人如何获得资源？
4. 为什么没有完全自由市场？
5. 主角凭什么打破垄断？
6. 打破垄断后会造成什么混乱？

## 6. 风险

1. 主角资源增长太快；
2. 宗门太蠢；
3. 货币体系不清；
4. 战争没有补给；
5. 强者只靠个人战斗，不受组织约束。
```

## 6. 世界模板类型

### 6.1 资源垄断型世界

适合：玄幻、修仙、经营、权谋。

核心冲突：谁控制稀缺资源，谁就控制阶层流动。

### 6.2 身份管制型世界

适合：都市悬疑、反乌托邦、赛博朋克。

核心冲突：人的身份、命运、权利由系统记录和分配。

### 6.3 神权合法性世界

适合：玄幻、奇幻、神秘学、宗教权谋。

核心冲突：统治合法性来自神意，但神意可能被解释、伪造或垄断。

### 6.4 帝国官僚世界

适合：权谋、历史、朝堂、科举、架空。

核心冲突：制度为了稳定而牺牲个体，个体为了生存必须理解制度。

### 6.5 记忆税型赛博世界

适合：科幻、赛博、悬疑。

核心冲突：记忆、身份、信用被货币化，真实自我被制度切割。

## 7. 共享世界规则

共享世界可以被多本小说使用，但必须遵守：

```text
1. 每本小说必须独立可读；
2. 共享世界核心规则不可随意修改；
3. 单本小说只能在自己的 branch 中扩展局部设定；
4. 影响共享世界主线的设定必须提交 world_merge_proposal；
5. 跨书彩蛋不能影响单本小说理解。
```

## 8. 世界规则分级

### 8.1 核心不可变规则

```text
世界第一规则
资源来源
力量代价
历史大事件
最高权力结构
核心灾难或系统机制
```

### 8.2 可局部变化规则

```text
地区制度
组织内部规则
市场价格
社会风气
某个势力的政策
局部法律执行方式
```

### 8.3 项目私有规则

```text
主角能力
局部案件
局部势力
人物关系
具体冲突
本书主题表达
```

## 9. 世界分支合并机制

单本小说如果产生了值得进入共享世界主线的新设定，必须提交：

```text
world_merge_proposal.md
```

模板：

```markdown
# 世界设定合并申请

## 来源项目

## 新增设定

## 影响范围

## 是否影响核心世界规则

## 是否与其他项目冲突

## 是否建议合并到共享世界主线

## 主编决策

接受 / 拒绝 / 仅保留在项目分支
```

## 10. 验收标准

一个世界模板必须回答：

1. 世界第一规则是什么；
2. 最稀缺资源是什么；
3. 谁控制资源；
4. 谁拥有权力；
5. 普通人如何生活；
6. 主角可以从哪里切入；
7. 能制造哪些长期冲突；
8. 容易出现哪些网文硬伤；
9. 适合哪些哲学命题；
10. 适合哪些商业爽点。
