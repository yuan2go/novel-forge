# Main Pipeline

## Command

```bash
./novel-forge run-pipeline --sample
```

## Steps

1. Import source material.
2. Clean text.
3. Decompose narrative/commercial mechanisms.
4. Extract knowledge.
5. Build reusable materials.
6. Generate topic.
7. Generate world.
8. Generate characters.
9. Generate outline.
10. Generate chapter plan.
11. Draft chapter.
12. Review draft.
13. Produce revision plan.
14. Import feedback.
15. Analyze feedback.

## Acceptance

A successful run creates a `WorkflowRun` JSON in `data/runs/` and a summary in `examples/sample_outputs/`.
