# Product Vision

## Module Goal

Novel Forge V5 is a long-running novel production system that converts reference analysis, multidisciplinary knowledge, reusable materials, and reader feedback into controlled fiction outputs.

## Inputs

- Source documents and comments.
- Cleaned text.
- Abstracted decomposition reports.
- Knowledge cards and material cards.
- Model outputs through adapters.

## Outputs

- Topics, worlds, characters, outlines, chapter plans, drafts, reviews, revision plans, and feedback insights.

## Path

Assets are separated under `data/` by lifecycle stage.

## Acceptance

The sample pipeline must run without external APIs and preserve copyright boundaries.
